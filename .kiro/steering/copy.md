# UI copy

- Short, plain words. Say "power", not "electricity supply" or "grid".
- One idea per line. Name the state: Normal, Your spot only, Possible, Confirmed, Restored.
- Say "Station offline" after 30 minutes of silence. Never "Power off" when we simply lost contact.
- Supply promise comparisons are labeled as an estimate. Never promise compensation.
- Simulated data is always labeled "Simulated".
- Optional Pidgin string pack, for example "Light don come!" for power restored. Keep strings in one file per language.
