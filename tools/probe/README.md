# tools/probe (throwaway)

Feasibility probe for Milestone 1. Spec: `.kiro/specs/feasibility-probe/`. Delete or archive after the gate decision (task 10).

| Folder | What | Check |
|---|---|---|
| `app` | Bare Expo app (SDK 58, Android only). Kotlin sensor and debug screen arrive in tasks 5 to 7. | `npm --prefix tools/probe/app run typecheck` |
| `worker` | Wrangler Worker with one SQLite-backed Durable Object `ProbeStore`. Endpoints arrive in task 4. | `npm --prefix tools/probe/worker run typecheck` |
| `analyze` | Pure analysis functions (Vitest). Task 3. | `npm --prefix tools/probe/analyze test` |

From the repo root: `npm run probe:install`, `npm run probe:typecheck`, `npm run probe:test`. These are separate from `npm test`, which needs no install.

Notes
- Lint is not set up: `eslint` is on the pending-approval list in `.kiro/approved-dependencies.json`. `tsc` is the only static check until the human approves it.
- `android/` is generated by `expo prebuild` (EAS) and is git-ignored. The Kotlin code in tasks 5 and 6 must therefore live in a local Expo module or config plugin, not in a hand-edited `android/` folder.
- The Worker secret `PROBE_TOKEN` is set by the human with `wrangler secret put PROBE_TOKEN`. It is never written to a file.
- The Expo template's `expo-status-bar`, `LICENSE` and iOS config were removed (not approved, no license chosen, Android only).
